# Рядом — анонимные чаты один на один

Светлый адаптивный сайт с оранжевым акцентом. Анкета без аккаунта → поиск по взаимным фильтрам → чат с кнопкой «Следующий». В шапке — только имя и возраст. Возраст участников: 18–99 лет.

## Открыть локально

Нужен Node.js 20 или новее. В папке проекта:

```sh
npm start
```

Откройте **http://localhost:3000**. Дополнительные пакеты не нужны. В Codex можно просто попросить: «Запусти превью проекта».

## Проверить все три экрана

1. Откройте сайт в двух вкладках. В каждой заполните имя, пол, возраст и фильтры.
2. Нажмите «Найти собеседника» в первой вкладке: появится поиск. Через 10 секунд без совпадений — сообщение «Пока никого нет…».
3. Начните поиск во второй вкладке с совместимыми фильтрами: обе перейдут в чат. Отправьте сообщение.
4. Нажмите «Следующий»: пара разорвётся, начнётся новый поиск с теми же фильтрами. Предыдущий собеседник увидит завершение диалога. Для новой пары откройте третью вкладку.

## Файлы и проверки

- `public/index.html` — три экрана.
- `public/style.css` — оформление и мобильная адаптация.
- `public/app.js` — интерфейс, поиск и сообщения.
- `server.js` — HTTP-сервер, сессии и подбор пар в памяти.
- `test/matching.test.js` — автоматические проверки: `npm test`.
- `package.json` — команды запуска и требования к Node.js.
- `.gitignore` — исключения для секретов и локальных файлов.

Сервер работает только на вашем компьютере. Данные исчезают после перезапуска. Каждая вкладка — отдельная сессия; перезагрузка возвращает к анкете. Закрытие вкладки завершает диалог; потерянные соединения удаляются примерно через 45–50 секунд. Сообщения обновляются раз в секунду. Это прототип без базы, модерации и сквозного шифрования. GitHub хранит исходный код; для работающего публичного сайта потребуется отдельный хостинг Node.js.
